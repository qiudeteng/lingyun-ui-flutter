# Changelog

All notable changes to this project will be documented in this file.

## 0.1.0 — 2026-09-17

### Added

- `LiquidGlassTokens` — blur, saturation, tint, edge highlight, border, opaque fallback, and shadow tokens with light/dark presets.
- `LiquidGlassTheme` — `ThemeExtension` with `of` / `tokensOf` helpers.
- `GlassSurface` / `GlassCard` — BackdropFilter glass with saturation, tint, edge highlight; opaque fallback for high-contrast / reduce-transparency.
- Example app with colorful wallpaper, light/dark and reduce-transparency toggles.
- Smoke tests for tokens and `GlassSurface`.
